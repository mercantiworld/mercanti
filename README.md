# Mercantiworld Landing Page

A simple, responsive landing page for Mercantiworld - making webshops easy.

## Overview

This is a clean, modern landing page built with Bootstrap 5 and custom CSS. The page features:

- Responsive design that works on desktop and mobile
- Embedded Loom videos showcasing customer and owner experiences
- Contact section with mailto functionality
- Mobile-optimized layout with sticky contact footer on small screens

## Features

- **Clean Design**: Minimal, professional layout using Raleway font
- **Responsive**: Mobile-first design with Bootstrap 5
- **Video Integration**: Embedded Loom videos for product demonstrations
- **Contact Integration**: Direct email link for easy customer contact
- **Performance Optimized**: Uses CDN resources for fast loading

- Bootstrap 5.3.0 (via CDN)
- Google Fonts - Raleway (via CDN)
